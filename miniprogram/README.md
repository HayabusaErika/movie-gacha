# 电影碰一碰 · 微信小程序

原生 WXML/WXSS/JS：抽卡、每日推荐、收藏、**安卓真 NFC 碰一碰**。

## 导入工程

开发者工具 → 导入项目 → 目录选 `miniprogram/`。
`project.config.json` 使用 `touristappid` 占位，使用云开发前请在开发者工具填写自己的 AppID。

## 功能

- **抽卡**：每天 3 次，随机抽一部电影（3D 翻转揭晓）。
- **每日推荐**：按日期确定性挑 3 部高分片，可收下 1 部。
- **收藏**：只显示自己拥有的卡，支持搜索；没有全量目录。
- **交换**：首页右上角「•••」→「碰一碰交换」，选 1–3 张后打开 NFC 交换。
- **手动添加**：粘贴豆瓣链接（片库内）。

卡片没有稀有度、没有战斗数值。片库 **2728 部**打包在 `data/library.js` 里，
只用于抽卡/推荐/解析链接，不会展示成目录。

## NFC

| 能力 | 安卓 / 鸿蒙微信 | iOS 微信 |
|---|---|---|
| HCE 广播（`wx.startHCE`） | ✅ | ❌ |
| 读卡（`NFCAdapter`） | ✅ | ✅ 仅 ISO-DEP |

界面上的按钮：

- **广播报价**：把选中的卡写成 NDEF 广播出去，60 秒自动停止。
- **停止广播**：手动停止。
- **读取对方**：开启读卡；读到 `offer` 显示对方卡，读到 `deal` 直接成交。
- **停止读卡**：关闭读卡。
- **广播成交**：把双方卡牌写成 `deal` 广播，本机立即生效。
- **模拟碰一碰**：没有第二台手机时演示用。

错误处理：不支持 HCE、NFC 未开启、读取失败都会在弹窗里给出提示，不会卡住。
进入/离开页面会自动停止广播与读卡。

## 已知限制

- iOS 不能广播，只能读安卓的标签。
- 交换只写本地存储，没有服务端记账。
- 海报版权归发行方，仅供本地个人演示。
- 正式发布需类目审核与备案；抽卡玩法容易被判游戏类目，建议先做体验版。

## 放映室（多人房间，云开发）

入口在首页底部「放映室」。进房后可点「邀请好友」发送微信分享卡片，也可用邀请码或二维码邀请：

| 能力 | 说明 |
|---|---|
| 创建 / 加入 | 6 位邀请码、扫码、微信分享卡片 |
| 房间抽卡 | 房间内任何人点「抽一张」，结果即时出现在墙上；消耗的是**发起人当天 3 次**，抽到的片同时进发起人收藏 |
| 从收藏加片 | 从自己的收藏挑一部放进房间，可以附 80 字推荐 |
| 实时同步 | 每 2.5 秒调用云函数拉取房间快照 |
| 昵称 | 默认取微信昵称，取不到时可手填 |

房间里只做「共享展示」，**不直接换卡**，交换仍然走碰一碰。

### 云开发准备

1. 开发者工具 → 云开发 → 开通 → 新建环境；
2. `miniprogram/config.js` 填 `cloudEnvId`（留空则用默认环境）；
3. 首次调用会自动建集合 `rooms`、`room_members`、`room_films`，权限保持默认即可（客户端不直连数据库，读写都走云函数）；
4. 右键 `cloudfunctions/room` → **上传并部署：云端安装依赖**；
5. 邀请二维码在本地生成（内容 `mg-room:邀请码`），对方用房间页的「扫码」即可加入；个人主体没有 `wxacode` 权限，云函数里的 `qrcode` 动作只给已认证主体备用。

### 房间数据

| 集合 | 字段 |
|---|---|
| `rooms` | `code`、`owner`、`title`、`createdAt`、`updatedAt` |
| `room_members` | `roomCode`、`openid`、`nick`、`avatar`、`joinedAt` |
| `room_films` | `roomCode`、`filmId`、影片字段、`source`（draw/library）、`review`、`addedBy`、`addedByName`、`createdAt` |

限制：房间最多 8 人、60 部片；推荐语 80 字；邀请码 6 位（去掉 0/O/1/I 等易混字符）。
